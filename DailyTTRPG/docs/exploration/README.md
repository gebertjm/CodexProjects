# Exploration Docs

Exploration uses the Surface / Focus / Commit interaction model:

- Surface: scene narration, automatic observations, and passive discoveries.
- Focus: immediate non-beat Closer Looks / Free Focus cards.
- Commit: one beat-consuming player action through the action window.
